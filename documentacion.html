Documentación de Replify v2.4

Bienvenido a la documentación oficial de Replify. Aquí encontrarás todo lo necesario para configurar, personalizar e integrar tu bot de WhatsApp con IA: desde la configuración inicial hasta la referencia completa de la API REST.

🚀 ¿Primera vez aquí? Comienza con la guía de Inicio rápido para tener tu bot activo en 5 minutos.

¿Qué es Replify?

Replify es una plataforma de automatización de WhatsApp Business potenciada por inteligencia artificial. Permite a cualquier negocio crear un asistente virtual que:

  • Responde preguntas frecuentes automáticamente, 24/7
  • Agenda citas y reuniones sin intervención humana
  • Gestiona pedidos, catálogos y pagos vía WhatsApp
  • Captura y califica leads automáticamente
  • Escala conversaciones al equipo humano cuando lo necesita

Inicio rápido — 5 minutos

Sigue estos pasos para tener tu primer bot de WhatsApp activo en menos de 5 minutos.

1

Crea tu cuenta

Ve a replify.ai/registro e ingresa tu email y nombre de negocio. No necesitas tarjeta de crédito.

2

Conecta tu número de WhatsApp

En el panel, haz clic en "Conectar WhatsApp". Puedes usar un número nuevo o conectar tu número actual mediante la API oficial de Meta.

3

Entrena tu IA

Sube un documento con información de tu negocio (PDF, DOCX o URL de tu sitio web). La IA aprende tu catálogo, precios, horarios y políticas automáticamente.

4

Define el tono y personalidad

Elige un nombre para tu bot, define su estilo de comunicación (formal, amigable, profesional) y configura el mensaje de bienvenida.

5

Activa y prueba

Haz clic en "Activar bot" y envía un mensaje de prueba a tu número. ¡Tu IA ya está respondiendo!

💡 Tip: Cuanto más detallada sea la información que le des a la IA, mejores serán sus respuestas. Puedes actualizar el entrenamiento en cualquier momento.

Conectar WhatsApp Business

Replify usa la API oficial de WhatsApp Business de Meta. Esto garantiza que tu número nunca será baneado y que tienes acceso a todas las funciones avanzadas.

Opción A: Número nuevo

Si quieres usar un número dedicado para el bot (recomendado):

  1. Ve a Panel → Números → Agregar número
  2. Elige "Número nuevo" e ingresa el número de teléfono
  3. Verifica con el código SMS recibido
  4. El número queda listo en 2-5 minutos

Opción B: Tu número actual

⚠️ Importante: Para migrar tu número actual a la API oficial, deberás desinstalar la app de WhatsApp Business en ese teléfono. El historial de chats anteriores no se migra.
  1. Desinstala WhatsApp Business del teléfono asociado al número
  2. En el panel, ve a Números → Migrar número existente
  3. Ingresa el número y verifica con SMS o llamada
  4. Configura el nombre de display y foto de perfil de tu negocio

Entrenar tu Inteligencia Artificial

La IA de Replify aprende de la información que tú le provees. Cuanto más contexto le des, más inteligentes y precisas serán sus respuestas.

Fuentes de conocimiento

Puedes entrenar tu IA con:

  • Documentos: PDF, DOCX, TXT con información de tu negocio
  • URL de tu sitio web: Replify extrae automáticamente el contenido
  • Google Sheets: Catálogos de productos, precios, inventario
  • Preguntas y respuestas manuales: Define respuestas específicas para preguntas clave
  • FAQ existente: Importa tu FAQ en formato CSV

Re-entrenamiento automático

Puedes configurar que Replify re-entrene la IA automáticamente cuando detecte cambios en tu sitio web o Google Sheets. Actívalo en Panel → IA → Auto-actualización.

API Reference — Autenticación

La API REST de Replify utiliza autenticación mediante Bearer Token. Obtén tu API key en Panel → Configuración → API.

Formato de autenticación

Incluye tu API key en el header de cada request:

# Header requerido en todos los endpoints
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
🔒 Seguridad: Nunca expongas tu API key en código del lado del cliente (JavaScript del navegador). Úsala solo en tu backend.

Base URL

BASE https://api.replify.ai/v2

API Reference — Mensajes

Enviar un mensaje

POST /messages/send
ParámetroTipoDescripción
to requeridostringNúmero de teléfono en formato E.164 (ej: +5215512345678)
message requeridostringTexto del mensaje a enviar (máx. 4096 caracteres)
fromstringID del número origen. Si solo tienes uno, es opcional.
template_idstringID de plantilla aprobada por Meta para mensajes fuera de ventana 24h

Ejemplo de request

{
  "to": "+5215512345678",
  "message": "Hola! Tu pedido #4821 ha sido enviado. 📦",
  "from": "num_abc123"
}

Ejemplo de respuesta

{
  "success": true,
  "message_id": "msg_7fG3kLm9",
  "status": "sent",
  "timestamp": "2025-05-22T14:32:10Z"
}

Obtener historial de conversación

GET /conversations/{contact_id}/messages

Webhooks

Configura webhooks para recibir notificaciones en tiempo real cuando ocurran eventos en tu cuenta Replify.

Eventos disponibles

  • message.received — Nuevo mensaje entrante
  • message.sent — Mensaje enviado por el bot
  • conversation.started — Nueva conversación iniciada
  • conversation.assigned — Conversación asignada a agente humano
  • contact.created — Nuevo contacto registrado
  • appointment.booked — Cita agendada vía bot

Formato del payload

{
  "event": "message.received",
  "timestamp": "2025-05-22T14:32:10Z",
  "data": {
    "contact_id": "cnt_9xH2mK",
    "phone": "+5215512345678",
    "message": "Hola, ¿tienen envío a Monterrey?",
    "conversation_id": "conv_3kLm7P"
  }
}
🔐 Validación de firma: Cada webhook incluye el header X-Replify-Signature con un HMAC-SHA256 de tu payload firmado con tu webhook secret. Valídalo siempre antes de procesar.
